========================================
App name: College Face

5) UX REQUIREMENTS (HOW IT SHOULD WORK)
========================================
On website load:
- If token exists in localStorage -> auto login UI state
- Load feed immediately

Login/Register:
- Modal opens on button click
- Successful login/register:
  - save token + user in localStorage
  - close modal
  - show logout button + userBadge
  - show toast success

Creating post:
- Must require login
- Select Post Type:
  - Normal Post
  - Notes
  - Confession

Notes type UX:
- When type=Notes:
  - show Notes Title + Subject inputs

Confession type UX:
- When type=Confession:
  - auto-enable Anonymous and lock it

Upload UX:
- Single upload input supports both image/* and application/pdf
- Preview optional (bonus)
- Submit creates post, clears form, refresh feed

Feed filtering:
- Sidebar filter instantly filters cached feed
- Search input filters posts by caption, username, category, subject, title
- Sort dropdown:
  - Latest: newest first
  - Top: sort by likes count

Trending filter:
- Trending shows top 20 posts based on likes count

Like:
- Click like toggles like/unlike
- Updates count immediately after refresh

Comment:
- Add comment requires login
- Post comment refreshes feed

Report:
- Confession posts have “Report”
- Clicking report asks reason prompt
- Sends to backend /api/posts/:id/report

Delete:
- Only post owner can delete own post
- Admin can delete any post via admin panel

7) BACKEND API (MUST)
========================================

POST /api/auth/register

Posts:

POST /api/posts/:id/comment (protected)

Admin:
POST /api/admin/login (super password from env)
GET  /api/admin/reports (admin only)
DELETE /api/admin/posts/:id (admin only)

9) SECURITY REQUIREMENTS (MUST)
========================================
- Passwords must never be stored plain text (bcrypt)
- JWT secret must be in .env
- Never send password back to frontend (serializeUser)
- Protected routes must require Bearer token
- Only post owner can delete own post
- Admin delete must be adminOnly middleware protected
- Upload security:
  - allow only images + pdf
  - limit file size (25MB)
  - store only file in /uploads
- AntiInspect.js is OPTIONAL and should not break localhost debugging:
  - allow devtools on localhost
- CORS:
  - allow CLIENT_URL and localhost ports
  - optional ALLOW_ALL_ORIGINS for development
