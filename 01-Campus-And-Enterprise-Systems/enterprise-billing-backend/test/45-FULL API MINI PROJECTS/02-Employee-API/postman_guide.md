# Postman Guide - Employee API

1. `GET /api/employees` - List all employees
2. `GET /api/employees/1` - Get single employee by ID
3. `POST /api/employees` - Add new employee
   Body: `{ "emp_code": "EMP004", "name": "Aman Verma", "email": "aman@company.com", "designation": "QA Analyst", "salary": 45000, "department": "QA" }`
4. `PUT /api/employees/1` - Update employee
5. `DELETE /api/employees/1` - Delete employee
