# Postman Guide - Blog API

1. `GET /api/posts` - List posts
2. `GET /api/posts/1` - Get single post
3. `POST /api/posts` - Create blog post
   Body: `{ "title": "Express Best Practices", "slug": "express-best-practices", "content": "Here are top tips...", "author_name": "Alex", "status": "published" }`
4. `PUT /api/posts/1` - Update post
5. `DELETE /api/posts/1` - Delete post
