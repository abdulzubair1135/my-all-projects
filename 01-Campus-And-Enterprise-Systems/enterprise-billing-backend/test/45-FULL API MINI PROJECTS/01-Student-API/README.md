# 01 - Student API Project

A complete, beginner-friendly Express.js + MySQL (mysql2/promise) REST API for Student Management.

## Setup Instructions

1. Import `schema.sql` into MySQL Workbench or phpMyAdmin.
2. Copy `.env.example` to `.env` and set your MySQL credentials.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the server:
   ```bash
   npm run dev
   ```
5. Test using Postman (refer to `postman_guide.md`).
