# Postman Guide - Product API

1. `GET /api/products` - List all products
2. `GET /api/products/1` - Single product
3. `POST /api/products` - Create product
   Body: `{ "sku": "MON-404", "title": "Gaming Monitor 27-inch", "description": "144Hz IPS Panel", "price": 18500, "stock": 10, "category": "Electronics" }`
4. `PUT /api/products/1` - Update product
5. `DELETE /api/products/1` - Delete product
