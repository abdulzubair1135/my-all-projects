# RentANY Multi-Platform Rental System

**Developer:** Shaikh Abdul Zubair Abdul Kabir  
**Domain:** 02-Offline-Mesh-And-Android-Systems  

## Description
Full-Stack Android Rental Marketplace built with Kotlin, Android Jetpack, and a Node.js backend. Features product rental listings, transaction tracking, and real-time order states.

## Architecture & Implementation
- Source code, configuration files, and system assets are preserved.
- Dependencies managed via respective environment manifests.
